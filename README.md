# 고1 3월 모의고사

2021~2026학년도 고1 3월 전국연합학력평가 수학 영역을 태블릿에서 풀어 보는 웹 앱입니다.

- **시험보기**: 30문항 100분, 또는 하프 모의고사(홀수번·짝수번 15문항) 50분. 답은 오른쪽 답안지에서 고르고(◀ ▶ 또는 번호로 문제 이동), 시간이 끝나면 바로 채점합니다. 풀이 보기에서 [내 풀이 고정하기]를 누르면 시험 때 쓴 글씨는 지워지지 않습니다.
- **연습하기**: 단원별 선택은 중학교 학년·단원별로 골라 풉니다(채점 기록 1차, 2차 … 남음). 문항별 선택은 원하는 문제를 골라(조건 검색 가능) 평가원 문제지 양식의 한글 파일(.hwpx, 문제 뒤에 정답·해설)로 저장하거나, [시험지 만들기]로 고른 문제만 시험처럼 풉니다(30문항 100분 비율).
- **오답노트**: 틀린 문제, 내가 쓴 풀이, 해설, 다시 푼 결과를 봅니다. 고른 문제를 내 필기와 함께 한글 파일로 저장할 수 있습니다.
- **실험실** (`lab.js`): 문제를 골라 세트로 저장하고, 문제 오른쪽 칠판에서 풀이합니다. 칠판 위 동그란 도구 버튼(지금 도구의 아이콘, 끌어서 옮김)을 누르면 선택·도형·선분·지우개·펜 칸과 색 세 가지가 한 바퀴 둘러싸고 펼쳐집니다(두 번 누르면 바로 펜, 선분을 누르면 평행선·수선·수직이등분선·각의 이등분선·접선). 도형은 누르면 점, 끌면 직선, 동그라미는 원, 꺾어서 닫으면 다각형(꼭짓점 A, B, C …), 길이·각 표시, 선이 만나면 교점(두 번 누르면 이름, 이름은 선과 겹치지 않는 곳에 생기고 끌어서 옮김). 선택은 끌면 옮기고, 빈 곳을 끌거나 꾹 누른 뒤 끌면 여러 개를 함께 고릅니다. 위 막대에는 되돌리기, 좌표축(옮긴 그림에 x축·y축이 있으면 그 원점), 수식(그래프·슬라이더), 모두 지우기, [?] 쓰는 법(처음 한 번은 저절로). 문제 아래 가로 답안지의 ★로 즐겨찾기, [그림 복사하기]로 문제 그림을 도형으로 옮기고 손잡이로 확대·축소합니다. 28문항은 미리 정확하게 만들어 둔 그림(`figs.js`)이 들어가고, 나머지는 미리 찾아 둔 그림 자리(`figs.js`의 `LAB_FIGBOX`)를 그 자리에서 읽어 바로 옮깁니다(포물선·반비례 곡선은 식으로 맞춤, 칠판 글자의 `a/x`는 위아래 분수로 씀).

펜 필기, 풀이 기록은 쓰는 기기의 브라우저에만 저장됩니다.
