# 고1 3월 모의고사

2021~2026학년도 고1 3월 전국연합학력평가 수학 영역을 태블릿에서 풀어 보는 웹 앱입니다.

- **시험보기**: 30문항 100분, 또는 하프 모의고사(홀수번·짝수번 15문항) 50분. 시간이 끝나면 바로 채점합니다.
- **연습하기**: 연도·번호별, 또는 중학교 학년·단원별로 골라 풉니다. 채점 기록(1차, 2차 …)이 남습니다.
- **오답노트**: 틀린 문제, 내가 쓴 풀이, 해설, 다시 푼 결과를 봅니다. 고른 문제를 내 필기와 함께 한글 파일로 저장할 수 있습니다.
- **파일 저장**: 원하는 문제를 골라(조건 검색 가능) 평가원 문제지 양식의 한글 파일(.hwpx)로 저장합니다.

펜 필기, 풀이 기록은 쓰는 기기의 브라우저에만 저장됩니다.

## 쓰는 방법

`index.html`(또는 `고1 3월 모의고사.html`)을 Chrome·Edge·Safari로 엽니다. 서버가 따로 필요하지 않습니다.

## 출처

문제·해설: 17개 시도교육청 주관 전국연합학력평가 고1 3월 수학 영역(2021~2026학년도), 자료 제공 EBSi.
문제와 해설의 저작권은 시행 교육청에 있으며, 수업 목적으로만 사용합니다.
